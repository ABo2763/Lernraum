☁️ Geräte synchronisieren

Die gleichen Karten und den gleichen Wiederholungsplan auf Laptop und iPad bearbeiten. Kostenlos mit einem eigenen Supabase-Konto.

1. Cloud-Verbindung einrichten

Erstelle auf supabase.com ein kostenloses Projekt. Führe danach das SQL aus der beiliegenden Datei supabase-einrichtung.sql im SQL Editor aus. Unter Project Settings → API Keys bzw. Connect findest du Projekt-URL und Publishable Key.

Die URL und der öffentliche Schlüssel werden nur auf diesem Gerät hinterlegt. Den geheimen service_role-Schlüssel niemals hier eingeben oder auf GitHub hochladen.

2. Auf beiden Geräten anmelden

Verwende auf iPad und Laptop dieselbe E-Mail-Adresse und dasselbe Passwort. Wenn du zum ersten Mal ein Konto erstellst, bestätige gegebenenfalls die E-Mail.

3. Ersten Abgleich sicher starten

Wichtig: Erstelle vorher in Lernraum ein JSON-Backup! Auf dem Gerät mit deinen bisherigen Karten wählst du In die Cloud hochladen. Auf dem anderen Gerät wählst du Aus der Cloud übernehmen. Danach werden Änderungen bei geöffneter App automatisch abgeglichen (etwa alle 30 Sekunden sowie nach dem Speichern).

Bitte beachten

  • Änderungen auf zwei Geräten gleichzeitig können einen Konflikt auslösen. In diesem Fall nichts überschreiben, zuerst Daten sichern und dann bewusst einen Stand auswählen.
  • Offline erstellte Karten bleiben zunächst lokal und werden nach Wiederherstellung der Verbindung abgeglichen, sofern kein Konflikt vorliegt.
  • Bildkarten können viel Cloud-Speicher und Datenvolumen benötigen. Das kostenlose Kontingent ist begrenzt.
  • Die App kann keine Synchronisierung durchführen, wenn sie auf allen Geräten geschlossen ist. Sie holt Änderungen beim nächsten Öffnen nach.
  • Ein gemeinsamer Cloud-Speicher ersetzt keine unabhängigen JSON-Backups.
